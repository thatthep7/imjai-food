# อิ่มใจ เดลิเวอรี 🍜

แอปสั่งอาหารจำลอง ไว้กดสั่งแก้หิวโดยไม่ต้องเสียเงินจริง ทำงานเหมือนแอปเดลิเวอรีทั่วไปครบทุกขั้นตอน ตั้งแต่เลือกร้าน เลือกตัวเลือกเมนู ใส่ตะกร้า ใช้โค้ดส่วนลด จ่ายเงิน ไปจนถึงดูคนขับวิ่งมาส่งบนแผนที่

> ร้าน เมนู คนขับ และการชำระเงินทั้งหมดสมมติขึ้น ไม่มีการสั่งอาหารหรือตัดเงินจริง

## มีอะไรบ้าง

- **19 ร้าน 19 แนว** ตามสั่ง, ก๋วยเตี๋ยวเรือ, ส้มตำ, ข้าวมันไก่, ซูชิ, ไก่ทอดเกาหลี, ติ่มซำ, เบอร์เกอร์, พิซซ่าเตาฟืน, สเต็ก, แกงอินเดีย, เฝอ, สลัดคลีน, บิงซู, ชานมไข่มุก, ข้าวต้มโต้รุ่ง, เม็กซิกัน, ข้าวหมกฮาลาล, หมูกระทะ
- **293 เมนู** (ร้านละ 13–21 เมนู) แบ่งหมวด มีป้ายขายดี/ใหม่/ร้านแนะนำ/ลดราคา
- **ตัวเลือกเมนูแบบแอปจริง** เนื้อสัตว์, ระดับเผ็ด, จำนวนพริก, ไข่ดาว, ขนาด, ความหวาน, ท็อปปิ้ง, ความสุกสเต็ก ฯลฯ พร้อมบังคับเลือก/เลือกได้สูงสุด และหมายเหตุถึงร้าน
- **ตะกร้า** แก้ไขรายการ, เพิ่ม/ลดจำนวน, สั่งได้ทีละร้าน (ถามก่อนเริ่มตะกร้าใหม่)
- **ชำระเงิน** เลือกที่อยู่ (เพิ่ม/แก้ได้), ส่งด่วน/มาตรฐาน/ประหยัด, ช้อนส้อม, โปรร้าน, โค้ดส่วนลด 4 ใบ, จ่ายด้วยวอลเล็ตจำลอง/เงินสด/QR จำลอง
- **ติดตามออเดอร์** แผนที่จำลองพร้อมคนขับเคลื่อนที่, 4 ขั้นตอนสถานะ, แชทกับคนขับ, ปรับความเร็วเวลาจำลองหรือข้ามขั้นได้, ยกเลิกได้ก่อนร้านรับ
- **หลังส่งถึง** ให้คะแนนอาหารและคนขับ, ทิป, สั่งอีกครั้ง
- ค้นหาร้าน/เมนู (สะกดได้หลายแบบ เช่น ราเมน/ราเมง และพิมพ์อังกฤษได้ เช่น pizza, ramen), หมวดอาหาร, ตัวกรองและการเรียง, ร้านโปรด, สุ่มเมนูตอนคิดไม่ออก
- ออกแบบสำหรับมือถือก่อน (safe area ของ iPhone, ปุ่มใหญ่กดง่าย, bottom sheet ปัดลงเพื่อปิดได้), โหมดมืด, ติดตั้งเป็นแอปบนหน้าจอโฮมได้
- ข้อมูลทั้งหมดเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น

## เปิดดูในเครื่อง

เป็นเว็บ static ล้วน ไม่ต้อง build ไม่ต้องติดตั้งแพ็กเกจ

```bash
cd imjai-food
python3 -m http.server 8000
# เปิด http://localhost:8000
```

ดับเบิลคลิก `index.html` เปิดตรง ๆ ก็ใช้งานได้ แต่จะติดตั้งเป็นแอปบนหน้าจอโฮมไม่ได้ (ต้องเปิดผ่าน http/https)

## Deploy ขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub เช่น `imjai-food` (Public)
2. push ไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (ให้ `index.html` อยู่ที่ root ของ repo)
   โฟลเดอร์ใน zip มี git และ commit แรกให้แล้ว ใช้แค่ 2 คำสั่ง:
   ```bash
   cd imjai-food
   git remote add origin https://github.com/<ชื่อผู้ใช้>/imjai-food.git
   git push -u origin main
   ```
   ถ้าไม่มีโฟลเดอร์ `.git` (เช่น ก็อปเฉพาะไฟล์มา) ให้เริ่มเองก่อน:
   ```bash
   git init && git add . && git commit -m "อิ่มใจ เดลิเวอรี" && git branch -M main
   ```
   หรือถ้าใช้ GitHub CLI สร้าง repo + push ได้ในคำสั่งเดียว: `gh repo create imjai-food --public --source=. --push`
3. ใน repo ไปที่ **Settings → Pages**
4. ที่ **Build and deployment → Source** เลือก **Deploy from a branch**
5. เลือก Branch **main** และโฟลเดอร์ **/ (root)** แล้วกด **Save**
6. รอประมาณ 1 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/imjai-food/`

ทุกพาธในโปรเจกต์เป็นพาธสัมพัทธ์ จึงใช้ได้ทั้งใน sub-path ของ GitHub Pages และโดเมนของตัวเอง ไฟล์ `.nojekyll` สั่งให้ GitHub ส่งไฟล์ตามที่เป็นโดยไม่ผ่าน Jekyll

### ติดตั้งลงมือถือ

- **iPhone (Safari):** เปิดลิงก์ → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
- **Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก**

### อัปเดตเวอร์ชัน

แอปใช้ service worker เก็บไฟล์ไว้ในเครื่องเพื่อให้เปิดเร็วและเปิดได้ตอนออฟไลน์ เมื่อแก้ไฟล์แล้ว push ใหม่ ให้เปลี่ยนค่า `VERSION` ใน `sw.js` (เช่น `imjai-v2`) ผู้ใช้จะได้ไฟล์ใหม่เมื่อเปิดแอปครั้งถัดไป

## โครงสร้างไฟล์

```
index.html              โครงหน้าเดียว (single-page app ใช้ hash router)
css/style.css           สไตล์ทั้งหมด ธีมสว่าง/มืด
js/data/options.js      หมวดร้าน, กลุ่มตัวเลือกเมนู, โค้ดส่วนลด
js/data/shops-*.js      ข้อมูลร้านและเมนู (แบ่ง 3 ไฟล์)
js/core.js              เก็บข้อมูล, ตะกร้า, คำนวณราคา, จำลองการส่ง
js/views-shop.js        หน้าแรก, ค้นหา, หน้าร้าน, หน้าต่างเลือกเมนู
js/views-cart.js        ตะกร้า/ชำระเงิน, ที่อยู่, โค้ด, สร้างออเดอร์
js/views-order.js       ติดตามออเดอร์, แชท, ประวัติ, หน้าฉัน
js/main.js              ตัวนำทาง, แถบล่าง, เริ่มแอป
sw.js                   service worker (ออฟไลน์ + ติดตั้งเป็นแอป)
manifest.webmanifest    ข้อมูลแอปสำหรับหน้าจอโฮม
icons/                  ไอคอนแอป
```

## เพิ่มร้านหรือเมนูเอง

เปิด `js/data/shops-1.js` (หรือไฟล์ไหนก็ได้) แล้วเพิ่มออบเจกต์ร้าน:

```js
{
  id: 'myshop', name: 'ร้านของฉัน', cat: 'thai', e: '🍲', c: ['#8E2F1D', '#F07A3A'],
  rt: 4.7, rv: 500, km: 1.2, t: [15, 25], fee: 15, lv: 1, tag: 'คำอธิบายสั้น',
  p: { k: 'off', amt: 20, min: 200 },           // โปรร้าน หรือใส่ null
  menu: [
    ['ชื่อหมวด', [
      // [ชื่อ, ราคา, อีโมจิ, คำอธิบาย, กลุ่มตัวเลือกคั่นด้วย , , ป้าย]
      ['ผัดกะเพรา', 50, '🌿', 'หอมกลิ่นกระทะ', 'meat,spice,egg', 'hot'],
    ]]
  ]
}
```

- `cat` ต้องตรงกับ id ใน `IJ.CATS` (`js/data/options.js`)
- `c` คือสีไล่เฉดของปกร้าน
- `p.k` เป็น `ship` (ส่งฟรี), `off` (ลดเป็นบาท) หรือ `pct` (ลดเป็น %, ใส่ `pct` และ `max`)
- กลุ่มตัวเลือกดูชื่อได้ใน `IJ.OPT` หรือสร้างกลุ่มใหม่เอง (`min: 1` คือบังคับเลือก)
- ป้าย: `hot` ขายดี, `new` ใหม่, `rec` ร้านแนะนำ, `sale:10` ลดจากราคาเดิม 10 บาท (ใส่หลายป้ายคั่นด้วยเว้นวรรค)
